# מדריך הקמה — שלב 1

המדריך כתוב למי שאינו מפתח. כל שלב מסביר גם *למה* הוא נדרש, לא רק מה ללחוץ.

זמן משוער: כשעתיים, רובן המתנה למסכים של Meta ו-TikTok.

---

## מה נבנה בשלב הזה

- חיבור מאובטח לאינסטגרם, לעמוד הפייסבוק ולטיקטוק
- יצירת פוסט בודד וקרוסלה, תזמון ופרסום
- **שער אישור ידני** — שום פוסט לא יוצא לאוויר בלי אישור מפורש שלך
- לוח בקרה עם יומן תוכן
- אחסון מדיה בענן

בנוסף, מהיום הראשון המערכת שומרת לכל פוסט את מאפייניו (פורמט, שעה, יום, אורך כיתוב, האשטגים)
ואת נתוני הביצועים שלו. שלב 1 לא מציג את הנתונים האלה — הם נצברים כדי שבשלב 3 יהיה על מה ללמוד.

## שלב א' — הכנת החשבונות שלך

### 1. אינסטגרם: המרה לחשבון מקצועי

ה-API של Meta לא מאפשר פרסום לחשבון אישי. בטלפון:

1. אינסטגרם → פרופיל → תפריט → **הגדרות ופרטיות**
2. **סוג חשבון וכלים** → **החלפה לחשבון מקצועי**
3. לבחור **Business** (מומלץ) או **Creator**

### 2. קישור לעמוד פייסבוק

זה הצעד שהכי הרבה אנשים נתקעים בו. פרסום לאינסטגרם דרך ה-API מתבצע בפועל
באמצעות הרשאה של **עמוד הפייסבוק** המקושר — בלי הקישור הזה, ה-API לא רואה את חשבון האינסטגרם בכלל.

1. אם אין לך עמוד פייסבוק עסקי — ליצור אחד ב-<https://www.facebook.com/pages/create>
2. אינסטגרם → הגדרות → **מרכז החשבונות** → קישור העמוד

**לאימות:** ב-<https://business.facebook.com/settings/instagram-accounts> חשבון האינסטגרם
צריך להופיע עם העמוד לצידו.

### 3. טיקטוק: חשבון Business

באפליקציה: פרופיל → הגדרות → **חשבון** → **החלפה לחשבון Business**.

## שלב ב' — אפליקציית המפתחים של Meta

### 1. יצירת האפליקציה

1. <https://developers.facebook.com/apps> → **Create App**
2. סוג: **Business**
3. לקשר ל-Business Portfolio שלך

### 2. הוספת המוצרים

בתפריט הצדדי **Add Product**:
- **Facebook Login for Business**
- **Instagram** → Instagram API setup with Facebook Login

### 3. הגדרת כתובת החזרה (Redirect URI)

תחת Facebook Login for Business → **Settings** → *Valid OAuth Redirect URIs*:

```
https://הכתובת-שלך/api/auth/meta/callback
```

> **חשוב:** Meta דורשת HTTPS גם בפיתוח. אם עדיין אין לך דומיין, ראה
> "מנהרה לפיתוח מקומי" בהמשך.

### 4. הוספת עצמך כ-Tester — הצעד שחוסך שבועות

זה הצעד שמאפשר להתחיל לעבוד **היום**, בלי App Review.

כל עוד מחוברים רק החשבונות שלך, האפליקציה יכולה להישאר במצב **Development** לצמיתות.
App Review נדרש רק כשמשתמשים אחרים מחברים את החשבונות שלהם.

1. באפליקציה → **App Roles** → **Roles** → **Add People** → **Instagram Tester**
2. להזין את שם המשתמש שלך באינסטגרם
3. **לאשר את ההזמנה:** אינסטגרם → הגדרות → **אפליקציות ואתרים** → **הזמנות Tester** → אישור

בלי שלב האישור הזה החיבור ייכשל עם שגיאת הרשאות מבלבלת.

### 5. העתקת המפתחות

**App Settings** → **Basic**: להעתיק את `App ID` ואת `App Secret` לקובץ `.env`.

## שלב ג' — אפליקציית המפתחים של TikTok

1. <https://developers.tiktok.com/apps> → יצירת אפליקציה
2. הוספת המוצרים **Login Kit** ו-**Content Posting API**
3. תחת Content Posting API להפעיל **Direct Post**
4. Redirect URI: `https://הכתובת-שלך/api/auth/tiktok/callback`
5. **Scopes:** `user.info.basic`, `user.info.stats`, `video.publish`, `video.list`
6. להעתיק `Client Key` ו-`Client Secret` ל-`.env`

### אימות דומיין האחסון — אל תדלג

טיקטוק מושך את קובץ הווידאו מכתובת ה-URL שלנו (`PULL_FROM_URL`), ומסרב למשוך
מדומיין שלא אומת. תחת **URL Properties** יש להוסיף ולאמת את הדומיין של
`S3_PUBLIC_BASE_URL`. בלי זה כל פרסום לטיקטוק ייכשל.

### מגבלת Self-only — שלב צפוי בתהליך, לא תקלה

עד שאפליקציית ה-API תעבור **Audit** רשמי:

- כל פוסט יפורסם כ-`SELF_ONLY` — גלוי רק לך
- **חשבון הטיקטוק עצמו חייב להיות מוגדר פרטי** ברגע הפרסום, אחרת טיקטוק דוחה את הבקשה
- **תוכן שפורסם במצב הזה לא הופך לציבורי רטרואקטיבית** אחרי אישור ה-Audit — צריך לפרסם אותו מחדש

המערכת אוכפת את זה בקוד: גם אם תבקש פרסום ציבורי, האדפטר יכפה `SELF_ONLY` כל עוד
`TIKTOK_CLIENT_AUDITED=false`. זה מכוון — כדי שהמערכת לא תייצר בקשה שטיקטוק יסרב לה.

## שלב ד' — אחסון מדיה

מומלץ **Cloudflare R2**: תואם S3, ובלי עמלות יציאה — משמעותי כי Meta וטיקטוק
מורידים את הווידאו מחדש בכל פרסום.

1. <https://dash.cloudflare.com> → **R2** → יצירת דלי
2. **Settings** → **Public access** → הפעלת גישה ציבורית (או חיבור דומיין משלך)
3. **Manage API Tokens** → יצירת טוקן עם הרשאת **Object Read & Write**
4. למלא ב-`.env`: `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_BASE_URL`

> **למה הדלי חייב להיות ציבורי לקריאה:** אינסטגרם וטיקטוק לא מקבלים העלאת קובץ בזרימה
> הזו — הם מקבלים כתובת ומורידים את הקובץ בעצמם, מהשרתים שלהם, ללא שום הרשאה.
> דלי פרטי יעבוד מצוין מהדפדפן שלך וייכשל בכל פרסום. המערכת בודקת את זה בזמן ההעלאה
> כדי שתגלה את הבעיה כשאתה מול המסך, ולא כשפוסט מתוזמן מפספס את מועדו.

## שלב ה' — הרצה

### התקנה

```bash
npm install
cp .env.example .env
```

### יצירת מפתחות ההצפנה

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

להריץ פעמיים ולמלא `ENCRYPTION_MASTER_KEY` ו-`SESSION_SECRET`.

> **מה המפתח הזה עושה:** טוקני הגישה לחשבונות שלך מוצפנים איתו לפני שהם נשמרים
> בבסיס הנתונים. מי שמשיג גיבוי של בסיס הנתונים בלי המפתח מקבל טקסט מוצפן חסר ערך.
> **בייצור המפתח שייך למנהל הסודות של שירות האירוח, לא לקובץ.**

### הפעלת בסיס הנתונים

```bash
docker compose up -d
npm run db:migrate
npm run create-owner
```

### הרצה — שני תהליכים

```bash
npm run dev          # הממשק
npm run dev:worker   # תהליך הפרסום המתוזמן
```

> **למה שני תהליכים:** הממשק מגיב לבקשות ונרדם ביניהן. הפרסום המתוזמן חייב תהליך
> שרץ ברציפות ומתעורר בעצמו ב-07:00 כדי לפרסם פוסט שאף אחד לא צופה בו כרגע.
> **אם תהליך העובד לא רץ — פוסטים מתוזמנים פשוט לא יפורסמו.**

### בדיקת תקינות

```bash
npm run check
```

עובר על כל ההגדרות ומדווח מה חסר, לפני שסומכים על המערכת שתפרסם.

### מנהרה לפיתוח מקומי

OAuth דורש כתובת HTTPS ציבורית גם בפיתוח:

```bash
npx cloudflared tunnel --url http://localhost:3000
```

להעתיק את הכתובת שמתקבלת ל-`APP_URL` ולרשימת ה-Redirect URIs אצל Meta ו-TikTok.

## שלב ו' — הפרסום הראשון

1. **חשבונות מחוברים** → חיבור Meta, ואז חיבור TikTok
2. **פוסט חדש** → העלאת תמונה, כתיבת כיתוב, בחירת יעדים
3. שמירה — הפוסט נכנס לתור **ממתין לאישורך**
4. **ממתין לאישור** → בדיקה → **אישור לפרסום**

רק בשלב 4 הפוסט נכנס לתור הפרסום בפועל.

**מומלץ לפרסום הראשון:** לתזמן לעוד חמש דקות, ולוודא שהוא באמת יוצא לאוויר —
כך מאמתים שתהליך העובד רץ כמו שצריך.

## פתרון תקלות

**"No Instagram professional account is linked to any Facebook Page"**
חשבון האינסטגרם אינו Business/Creator, או שאינו מקושר לעמוד. ראה שלב א'.

**"הקובץ הועלה אבל אינו נגיש לציבור"**
הדלי אינו ציבורי לקריאה. ראה שלב ד'.

**פוסט מתוזמן לא פורסם**
לבדוק שתהליך העובד רץ (`npm run dev:worker`) ושהפוסט אושר. פוסט לא מאושר
נשאר בתור לנצח — במכוון.

**"TikTok will not accept a Self-only post from this account"**
חשבון הטיקטוק ציבורי בזמן שאפליקציית ה-API עדיין לא עברה Audit. להעביר את החשבון
למצב פרטי, או להשלים את ה-Audit.

**החיבור פג אחרי חודשיים**
טוקנים של Meta פגים כעבור כ-60 יום. תהליך העובד מחדש אותם אוטומטית פעמיים ביום —
אבל רק אם הוא רץ. אם המערכת הייתה כבויה שבועות, ייתכן שיידרש חיבור מחדש.
